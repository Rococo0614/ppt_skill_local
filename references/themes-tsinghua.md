# 清华大学风格 · 主题色预设（Tsinghua Themes）

4 套基于清华大学校色的高反差配色。**每套都遵循"高级灰白底 + 单一清华紫锚点色"原则**——学术、庄重、理性,延续瑞士国际主义风的一切硬规则（无衬线、直角、无渐变无阴影、单一 accent、8px 网格）。

> 基底:清华紫校色 `#660874`（Tsinghua Purple）。紫是校徽主色,自带"严谨 / 人文 / 技术报国"的学术气质,替代 Swiss 风的 IKB 蓝成为唯一锚点。

---

## 使用方法

1. 问用户选哪套（或基于内容推荐一套）
2. 打开 `assets/template-tsinghua.html` 的 `<style>` 块
3. 找到开头的 `:root{` 块
4. **整体替换**标有"主题色"注释的所有变量：`--paper` / `--paper-rgb` / `--ink` / `--ink-rgb` / `--grey-1` / `--grey-2` / `--grey-3` / `--accent` / `--accent-rgb` / `--accent-on` / `--accent-bright`
5. 其他 CSS 都走 `var(--...)`,无需任何其他改动

## 🟣 清华紫 (Tsinghua Purple · 标准校色)

**适合**：通用场合、学术汇报、科研答辩、毕业分享、校庆/系庆主题、不知道选啥的默认。
**调性**：纯白底 + 标准清华紫 `#660874`,庄重、理性、有学术权威感,像清华校徽和官方视觉体系。

```css
--paper:#fafaf8;
--paper-rgb:250,250,248;
--ink:#0a0a0a;
--ink-rgb:10,10,10;
--grey-1:#f0f0ee;
--grey-2:#d4d4d2;
--grey-3:#737373;
--accent:#660874;
--accent-rgb:102,8,116;
--accent-on:#ffffff;
--accent-bright:#A55FCC;
```

**使用要点**：
- `#660874` 是深紫,大色块（`.accent-block` / 封面 `.slide.accent`）上反白文字可读性极好
- 紫色大面积铺开有"校徽庄重感",但不要满屏紫——它比 IKB 更沉,滥用会压抑
- `--accent-bright:#A55FCC` 用于暗底高亮（如 `dark` 页的强调字）,提亮后依然可辨

## 🍇 深紫菫 (Deep Violet)

**适合**：夜间发布会、暗场演讲、庄重场合、历史/校史题材。
**调性**：更深的紫 `#4B086D`,沉稳、厚重,配合 `dark` 主题页黑底紫光最高级。

```css
--paper:#fafaf8;
--paper-rgb:250,250,248;
--ink:#0a0a0a;
--ink-rgb:10,10,10;
--grey-1:#f0f0ee;
--grey-2:#d4d4d2;
--grey-3:#737373;
--accent:#4B086D;
--accent-rgb:75,8,109;
--accent-on:#ffffff;
--accent-bright:#8E4BB3;
```

**使用要点**：
- 和标准紫差异微妙,主要用在暗场投影——浅屏上看不出区别,暗屏上更沉稳
- 适合与 `dark` 页 1:1 交替,紫光在近黑底上非常"学术夜"
- 小字号文字上的紫色会偏暗,meta/kicker 用 `--accent-bright` 提亮

## 🔮 丁香紫 (Lilac)

**适合**：人文、艺术、教育、女生向内容、轻松的学术分享、招新/迎新主题。
**调性**：浅丁香紫 `#A66FD1`,轻盈、亲和,像校花紫荆花,年轻但不失克制。

```css
--paper:#fafaf8;
--paper-rgb:250,250,248;
--ink:#0a0a0a;
--ink-rgb:10,10,10;
--grey-1:#f0f0ee;
--grey-2:#d4d4d2;
--grey-3:#737373;
--accent:#8E3FB5;
--accent-rgb:142,63,181;
--accent-on:#ffffff;
--accent-bright:#C48AE0;
```

**使用要点**：
- `#8E3FB5` 介于校色紫和亮紫之间,兼顾校色识别度和屏幕显色亮度
- 白字反色依然可读,不需要像柠檬黄那样换黑字
- 适合"轻松学术"——课程分享、社团、科普,比标准紫少一点仪式感

## ⚗️ 紫灰学术 (Violet Grey · 学术灰)

**适合**：严谨的研究报告、论文汇报、数据密集型 deck、工程师/科研团队内部评审。
**调性**：低饱和紫灰 `#6B4E8E`,最克制的学术气质,像老图书馆的装帧,压得住满屏数据。

```css
--paper:#fafaf8;
--paper-rgb:250,250,248;
--ink:#0a0a0a;
--ink-rgb:10,10,10;
--grey-1:#f0f0ee;
--grey-2:#d4d4d2;
--grey-3:#737373;
--accent:#6B4E8E;
--accent-rgb:107,78,142;
--accent-on:#ffffff;
--accent-bright:#9A7CC0;
```

**使用要点**：
- 饱和度最低的一档,紫只作为"有温度的高级灰"出现,几乎不抢内容
- 图表、KPI 塔、bar-fill 大面积用都不会刺眼,数据页首选
- 想要"低调校色暗示"而非"紫色宣言"时选它

## 切换原则

- **一份 deck 只用一套主题**,不要中途换紫
- 灰阶变量（`--grey-1/2/3`）在 4 套主题里完全相同,无需调整
- WebGL 网格背景会自动读取 `--accent` 变量,翻页时鼠标附近会偷渡一抹紫色（`readAccent()` 的兜底 hex 已改为 `#660874`）
- ASCII 封面呼吸场走 `mix-blend-mode:screen`,紫色底上白字符自然发亮,不用改 JS
- 选定主题后,可以在 chrome 文案里用一个相关词强化语义（如标准紫配 `Tsinghua / Academic`,紫灰配 `Research / Archive`）

---

## ❌ 不要做的事

- ❌ **不允许混搭**（例如清华紫 + IKB 蓝同时出现作高亮）——彻底违反"单一锚点色"原则
- ❌ **不允许用户自定义任意 hex 值**——委婉拒绝,展示 4 套预设让选
- ❌ **不要改灰阶变量**——`--paper` / `--grey-1/2/3` / `--ink` 跨主题统一,只换紫色
- ❌ **不要用渐变**——清华风同样拒绝任何渐变,所有色块必须纯色
- ❌ **不要给 accent 加阴影 / 圆角 / 透明度**——直角、纯色、不透明,硬规则不变
- ❌ **不要插入校徽 / 校名 logo 图片**——单文件 HTML 无法保证 logo 版权与清晰度,用文字元数据（`Tsinghua · 自强不息 厚德载物`）表达校色语义即可,除非用户明确提供授权素材

## 关于灰阶（跨主题统一）

| 变量 | 值 | 用途 |
|---|---|---|
| `--paper` | `#fafaf8` | 主底色（极浅暖白） |
| `--grey-1` | `#f0f0ee` | 浅灰底（用于 `.grey-block` / 区块底） |
| `--grey-2` | `#d4d4d2` | 中灰（分割线、border） |
| `--grey-3` | `#737373` | 暗灰（辅助文字 / meta） |
| `--ink` | `#0a0a0a` | 文字主色（近黑） |

这套灰阶与 Swiss 风完全相同,是经过校色的"高级灰",在任何紫色下都不抢戏。**不要**改成纯白（`#fff`）或纯黑（`#000`）。
